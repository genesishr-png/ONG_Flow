# ONG Flow

Sistema de gestão para ONGs.

## Estrutura do Projeto

O projeto está dividido nos seguintes componentes:

- `api`: Backend (NestJS)
- `app`: Mobile/Web App (Next.js/React Native)
- `backend`: Lógica de negócio compartilhada
- `frontend`: Interface de usuário
- `prisma`: Configurações de banco de dados e ORM
